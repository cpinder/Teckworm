About the Windows Operating System

The operating system consists of a number of programs and services that run on a device so humans can interact with and use the device. The OS manages everything, such as hardware resources, internet connections, security features and updates, just to name a few.

The OS takes input from devices like the keyboard, manipulates programs based on those inputs, and then performs actions such as sending data to the router so it can be transmitted across the internet.

Windows Architecture Overview

To make it easier to understand Windows, we can break it into three logical parts: the applications we interact with, the system services that coordinate functionality, and the kernel that gives commands to the CPU.

Operating system kernel

The kernel takes OS requests from system services and translates those into instructions that are passed to the individual hardware devices inside the computer.

System services

System services are software components that interact with other software to coordinate them. They provide higher-level functions that require multiple systems to work together.

.NET Framework, Win32 and Apps

The .NET Framework is composed of tools, programming languages and libraries to run and write applications. Win32 apps provide software direct access to system hardware and the highest performance.

Types of Windows apps

  • Traditional desktop apps (Win32 / .NET)
  • Microsoft Store apps (Windows RT APIs)

The Windows Registry

The registry is a hierarchical database that stores user and computer configuration settings. Registry keys hold things like the file path to an executable, server names and OS settings.

Major registry hives

  • HKEY_CLASSES_ROOT: File type associations
  • HKEY_CURRENT_USER: Settings for the signed‑in user
  • HKEY_LOCAL_MACHINE: System‑wide configuration
  • HKEY_USERS: Settings for all users
  • HKEY_CURRENT_CONFIG: Current hardware profile

Important: Registry changes take effect immediately and cannot be undone.

Windows Fixes and Diagnostic Tips

Find and uninstall a program

  1. List installed software: Get-WmiObject -Class win32_product
  2. Locate uninstall string in registry
  3. Run uninstall command via msiexec.exe

Remove a Windows user profile

Delete the profile key under:

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProfileList

Bluetooth

Used to connect two devices that are close to each other (~30 feet). Common in wireless earbuds, wireless printers, etc. Switches frequency hundreds of times a second. Devices must be paired first.

NFC (Near-Field Communication)

Connects devices over very short distances (~4 inches). Commonly used for mobile payments, like Google Pay.

DHCP (Dynamic Host Configuration Protocol)

Allows for automatically assigning and reserving IP addresses for connected devices. Can provide default gateway, domain name, DNS servers and time server info.

In small office/residential settings DHCP is often handled by the router. In an enterprise setting DHCP runs on a server instance and devices connect and renew IP leases.

(https://commons.wikimedia.org/)

DNS (Domain Name System)

Provides a naming system for resources on the internet or other IP networks. Converts a common name to the IP address of the resource. It consists of distributed servers maintaining the domain name hierarchy and IP address spaces.

The “phone book” of the internet. URLs and email addresses use DNS to find the IP to locate or send data.

  • A, AAAA records
  • SMTP mail (MX)
  • CNAME aliases

Hierarchical structure (right to left): www.ITSupport.teckworm.com

  • .com — root
  • .teckworm — subdomain
  • .departments — subdomain of teckworm

Uses caching servers to speed up requests; devices also have DNS cache to speed up lookups.

Encryption

Converts plain-text into unreadable form without a decryption key. Ensures confidentiality and protects data at rest and in transit. Can use symmetric keys (same key for sender/receiver) or public keys (receiver has private key).

TLS (Transport Layer Security)

Uses encryption to provide secure communications for services like email, VoIP phones, HTTPS requests and more. Operates at the application layer.

Firewall

A network device (or software) that monitors network traffic and allows or blocks inbound/outbound traffic based on rules. Evaluates packets by:

  • Direction (inbound/outbound)
  • Source/destination IP
  • Port
  • Protocol
  • Application (some firewalls)
  • Action: Allow / Deny / Drop / Forward

Firewalls protect corporate networks from the public internet and individual devices as part of security suites. Windows includes “Windows Firewall with Advanced Security.”

OSI Model (Open Systems Interconnection)

*7 layer bean dip (Flickr)

  1. Application: User-facing services (Mail, Directory, File Shares). Protocols: DHCP, DNS, FTP, HTTP, HTTPS, IMAP, LDAP, SSH, TLS/SSL.
  2. Presentation: Translation layer. Formatting, encryption, compression. JPEG, GIF, TLS, SSL.
  3. Session: Establish, manage, terminate sessions.
  4. Transport: ACK, retransmission, port numbers. Data in segments. Protocols: TCP, UDP.
  5. Network: Routing packets using IP addresses. Protocols: ICMP, IPsec.
  6. Data Link: Frame-level communication using MAC addresses. Protocols: ARP, PPP, MAC.
  7. Physical: Cables, hubs, modems. Bits. Bit rate, duplex modes.

Example (sending an email): User types message → data formatted/encrypted → session established → data segmented → segments become packets → packets become frames → frames transmitted as bits → reverse process on receiving device.

Security Threats

Social Engineering

Uses psychological manipulation (fear, urgency, empathy) to trick a person into sharing sensitive data or taking harmful actions. Phishing is the most common form.

Spoofing

Attackers create fake webpages, email addresses, phone numbers or domains that appear legitimate. Victims then divulge private information.

Ransomware

Attackers encrypt a victim’s files and demand payment to decrypt them. File extensions change and victims cannot open their own documents.
